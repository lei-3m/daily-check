## 1. 주간 뷰 좌우 스와이프

```
주간 뷰에 좌우 스와이프로 이전/다음 주 이동을 추가해 주세요.
월 달력에 이미 구현된 방식과 동일하게 만듭니다.

- 손가락을 실시간으로 따라 움직여야 합니다.
  드래그 중 이전 주의 오른쪽 일부가 들어오는 식으로,
  월 달력과 같은 동작입니다.
- 손을 뗄 때 판정: 이동 거리가 주간 뷰 폭의 25% 이상이거나
  빠르게 튕겼으면 전환, 아니면 원래 자리로 복귀.
- 드래그 중에는 transform만 조작하세요. React 상태를 매 프레임 갱신하지 마세요.
- ‹ › 버튼은 그대로 유지합니다.

## 충돌 방지 (중요)

주간 뷰 바로 아래에 dnd-kit 드래그 정렬이 있는 할 일 목록이 있습니다.

- 스와이프 감지는 주간 뷰 영역 안에서만 동작해야 합니다.
  할 일 목록 영역으로 제스처가 새어나가면 안 됩니다.
- 세로 이동이 가로보다 크면 스와이프로 판정하지 말고
  페이지 세로 스크롤을 그대로 통과시키세요.
  주간 뷰는 화면 중간에 있어서, 스크롤 중 손가락이 옆으로 흐르면
  의도치 않게 주가 넘어갈 수 있습니다.
  월 달력보다 판정을 더 보수적으로 잡으세요.
  (예: |dx| > |dy| * 2 이고 |dx| > 40px 일 때만 드래그 시작)
- 날짜를 탭할 때 스와이프로 오인되지 않아야 합니다.
- prefers-reduced-motion에서는 애니메이션 없이 즉시 전환합니다.
```

### 확인 (폰에서)

- [ ] 페이지를 **세로로 스크롤**할 때 주가 안 넘어가는가
- [ ] 할 일을 **드래그로 정렬**할 때 주간 뷰가 안 움직이는가
- [ ] 날짜 탭이 정상 동작하는가

첫 두 개가 걸리면 `|dy| * 2` → `* 2.5`, `40px` → `60px`로 올리세요.

### 8-A. Edge Function (콘솔 작업)

Supabase 대시보드 → Edge Functions → 새 함수 생성. API 키는 함수의 환경변수(Secrets)로 등록하고 클라이언트에는 절대 노출하지 않습니다.

### 8-B. 프롬프트

```

        다른 사람이 기다리는 중
```

## 저장소에 넣을 규칙 파일

AI 코딩 도구가 매번 같은 실수를 반복하지 않도록, 저장소 루트에 규칙 파일을 두세요. Claude Code는 `CLAUDE.md`, Codex는 `AGENTS.md`를 읽습니다. **같은 내용으로 두 파일을 만들어 두면 도구를 바꿔도 그대로 적용됩니다.**

```markdown
# Daily Check — 작업 규칙

하루 단위 체크리스트 웹앱. React + TypeScript + Vite + Tailwind.
Supabase(인증·DB), Vercel(배포). **백엔드 서버는 없습니다.**

전체 사양은 `docs/기획서-daily-check.md`를 먼저 읽으세요.

## 절대 규칙

1. **`toISOString()` 사용 금지.** 날짜 키는 로컬 타임존 기준 "YYYY-MM-DD".
   UTC 변환으로 한국 시간 오전 9시 이전에 하루가 밀립니다.
   `src/lib/date.ts`의 함수를 쓰세요.

2. **📋 복사의 출력 형식은 마크다운 `- [ ]` / `- [x]`.**
   화면 체크박스 모양이 바뀌어도 클립보드 내용은 절대 바뀌면 안 됩니다.
   이것이 이 앱의 존재 이유입니다.

3. **저장소 접근은 `src/lib/storage.ts`만 통과.**
   컴포넌트에서 localStorage나 supabase를 직접 호출하지 마세요.

4. **`service_role` 키를 코드에 넣지 마세요.**
```
